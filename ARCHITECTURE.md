# HH Презентер — архітектура

Один вихідний застосунок (`sales-hub/`) → кілька збірок. Усе працює без сервера: звичайні HTML/JS/медіа.

## Шари

| Шар | Файли | Що змінюють |
|---|---|---|
| Оболонка й екрани | `index.html` (екрани `<section class="screen">`, переходи, показ слайдів, листи) | рідко |
| Поведінка | `features.js` (меню, контакти й QR-візитка, база контактів, фотобанк, «Надіслати»), `touch.js` (жести, свайпи, «Назад»), `i18n.js` (UA/EN) | рідко |
| Дані (лише факти з джерел) | `data.js` (моделі з сайту, `tools/build_data.py`), `capacity.js`, `presentations.js`, `production.js`, `photobank.js`, `extra_videos.js`, `military.js` | при додаванні матеріалів |
| Переклад | `i18n_en.js` (точні рядки), `anatomy_en.js` («Анатомія») | разом із новими текстами |
| Профіль менеджера | `profile.js` (у загальній збірці `null`), `profiles/<id>.json` | новий менеджер — новий json |
| Медіа | `media/…` (фото, відео, сторінки презентацій, PDF) | при додаванні матеріалів |
| Офлайн | `assets.js` (список файлів, `tools/build_assets.py`), `sw.js` | автоматично |

## Збірки

| Збірка | Як | Офлайн | Що всередині |
|---|---|---|---|
| **Android APK, загальний** | GitHub Actions `android.yml` при пуші в `main` | усе вбудовано в APK | увесь `sales-hub` (без `tools`, `profiles`) |
| **Android APK, персональний** | той самий workflow, для кожного `profiles/<id>.json` | усе вбудовано | те саме + `profile.js` з даними менеджера; власний пакет `ua.hobbithouse.presenter.<id>` і назва — ставиться поруч із загальним |
| **iPad / браузер, закрита** `…/ipad/` | `tools/publish_public.sh` → `build_ipad.py` | після першого входу автоматично докачує все | усе, зашифровано паролем (AES-256-GCM) |
| **Веб, відкрита для клієнтів** | `tools/publish_public.sh` → `build_public.py` | кеш браузера | без «Менеджеру», військових креслень, «Створення виробництва», сертифікатів PDF, профілів |
| iOS (Xcode) | `ios.yml`, вручну | вбудовано | загальна |

## Профіль менеджера (персональна збірка)

`profiles/<id>.json`: `id` (латиниця, як ім'я файлу), `name`, `name_en`, `given`, `family`, `phone`, `email`, `app_name`.
Необов'язково `videos`: `[{file, thumb, title, desc}]` — власні відео менеджера; файли лежать у `profiles/<id>/media/`, у збірці — `media/profiles/<id>/`, показуються першою групою «Додаткові відео» в розділі «Відео» лише в його APK.
Необов'язково `production_videos` (той самий формат + `lang`) — замінюють відео «Створення виробництва» в його збірці; старі відео з неї прибираються.
Перевіряє й записує `tools/build_profile.py <id> <папка>`. Що змінюється в застосунку:
- «Контакти»: перша вкладка QR — його візитка (vCard), у списку першими його телефон і email; кнопка «Зберегти візитку» віддає його vCard;
- підписи всіх листів (моделі, презентації, інвесторам; UA/EN/DE) — його ім'я, телефон, email;
- у шапці меню — «Презентер · <ім'я>»; англійською — `name_en`.

Додати менеджера: новий `profiles/<id>.json` → пуш у `main` → у релізі з'явиться `HobbitHouse-Presenter-<id>.apk`.

## Додати матеріали

- Презентація: `python3 tools/add_presentation.py <pdf> <slug>` (+ запис у `presentations.js`); для інвесторів — `… <slug> media/production` (+ `production.js`).
- Відео: стиснути (`ffmpeg … -crf 23 -maxrate 4500k -movflags +faststart`), мініатюра `.jpg` поруч, запис у `extra_videos.js` або `production.js`.
- Нові фото: `python3 tools/build_thumbs.py` (мініатюри для дрібних карток).
- Після змін: `python3 tools/build_assets.py`, коміт, пуш у `main`, `bash tools/publish_public.sh`.

## Правила

- Лише факти з джерел (сайт, КП, презентації, сертифікати, `data/*.md`). Не вигадувати.
- Закрите не публікувати: `build_public.py` сам прибирає й перевіряє (зупиняє публікацію, якщо щось лишилось).
- Сертифікати не надсилаються клієнтам.
